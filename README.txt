Как выложить приложение на свой хостинг
1. Загрузите все файлы из этой папки в одну папку на сайте с HTTPS (index.html должен открываться по адресу сайта).
2. Откройте сайт на телефоне. Android: меню браузера, «Установить приложение». iPhone: Safari, «Поделиться», «На экран Домой».
3. Первый раз откройте с интернетом: после этого приложение, Библия и последние события и объявления откроются без связи.
4. Когда появится сервер, впишите его адрес в index.html в строку CFG={api:'' ...} и включите CORS для сайта приложения.
Папка api на этом же сайте не кэшируется, данные с сервера всегда свежие.
